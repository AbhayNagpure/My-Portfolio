# MERN Project Scaffold

This workspace is set up as a MERN starter project with separate `frontend` and `backend` packages.

## Structure

- `frontend/` - React application built with Vite
- `backend/` - Express API with MongoDB connection

## Commands

From the workspace root:

- `npm install` - installs dependencies for both frontend and backend
- `npm run start:frontend` - starts the React app
- `npm run start:backend` - starts the Express API

## Features

- Portfolio API at `https://my-portfolio-p3yl.onrender.com/api/portfolio`
- Contact form POST endpoint at `https://my-portfolio-p3yl.onrender.com/api/contact`
- React frontend with hero, about, skills, projects, testimonials, and contact sections

## Notes

Update `backend/.env` with your MongoDB connection string before starting the backend.
